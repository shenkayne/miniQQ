# miniQQ 功能介绍（实现清单）

本文档用于说明本项目（miniQQ）已经实现的主要功能点，便于课程设计汇报与咸鱼售卖展示。

---

## 1. 总体说明

- 架构：C/S（客户端 QQClient + 服务端 QQServer + MySQL）
- 客户端：Java Swing 图形界面
- 服务端：Socket（TCP 业务命令 + UDP 消息转发）+ JDBC 连接 MySQL
- 数据存储：MySQL（用户、好友、登录状态、密保、聊天记录等表）

---

## 2. 客户端（QQClient）功能

### 2.1 登录

- 输入 QQ 号与密码登录
- 登录成功后进入主界面
- 重复登录检测（服务端返回 reLogin 时提示）

### 2.2 记住密码

- 登录界面提供“记住密码”选项
- 可保存/读取上一次登录信息（用于下次自动填充）

### 2.3 注册

- 支持注册新用户
- 注册信息包含：密码、签名、头像、昵称、性别、生日、电话、邮箱、地址
- 支持设置 3 组密保问题/答案
- 注册成功后返回新 QQ 号

### 2.4 找回密码

- 输入 QQ 号可获取密保题目与答案
- 可得到该账号密码

> 说明：该实现符合课程设计演示，但真实产品中不应明文返回密码。

### 2.5 主界面（好友列表）

- 显示好友列表
- 显示好友在线/离线状态
- 支持好友分组显示（SubGroup）

### 2.6 搜索用户

- 支持按 QQ 号或昵称查询用户（服务端 queryUser1）
- 查询结果展示用户基础信息（QQ/昵称/签名/头像等）

### 2.7 添加好友

- 支持添加好友
- 选择分组添加
- 添加成功后刷新好友列表

### 2.8 删除好友

- 支持删除好友

### 2.9 聊天窗口

- 点击好友打开聊天窗口
- 文本消息发送与接收
- 聊天界面支持气泡显示与自定义样式（依赖 MigLayout / NinePatch 相关组件）

### 2.10 资源与界面美化

- 内置头像/按钮/背景/表情等 UI 素材（`image/` 目录）
- 支持表情（gif）展示

---

## 3. 服务端（QQServer）功能

### 3.1 服务器控制台界面

- 提供服务端 GUI 控制窗口（ServerFrame）
- 显示在线用户列表与数量
- 支持启动/暂停监听线程

### 3.2 TCP 业务处理

服务端通过 TCP 接收客户端命令并处理：

- login：登录验证、重复登录判断、写入在线状态
- registerNewUser：注册新用户、写入密保信息
- queryUser/queryUser1：查询用户信息
- queryFriend：获取好友列表与在线状态
- addFriend：添加好友（双向写 Friends 表）
- deleteFriend：删除好友
- getPwd：找回密码信息返回（演示）
- logout/end：退出与断开连接

### 3.3 UDP 消息转发

- 服务端监听固定 UDP 端口接收消息对象（Message）
- 按消息类型进行转发：
  - TXT（文本消息）
  - Shake（抖动）
  - Record（聊天记录相关）
  - Notice（会话建立/端口协商通知）

### 3.4 聊天记录写入数据库

- 服务端在转发消息时将文本与样式写入数据库（Text/ChatInfo 等表结构）

---

## 4. 数据库（MySQL）功能点

- 用户信息：`UserInfo`
- 好友关系：`Friends`
- 分组信息：`SubGroup`
- 登录状态：`Login`
- 密保信息：`GetPwdInfo`
- 聊天文本与格式：`Text`
- 聊天记录索引：`ChatInfo`
