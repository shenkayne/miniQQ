# miniQQ 聊天软件课程设计报告

## 摘要

本课程设计实现了一个简化版 QQ 聊天软件（miniQQ）。系统采用 C/S 架构：客户端使用 Java Swing 实现图形界面，服务端基于 Socket 进行连接管理与业务处理，并通过 JDBC 访问 MySQL 数据库完成用户信息、好友关系、登录状态等数据的持久化。

关键词：Java；Swing；Socket；JDBC；MySQL；即时通信

---

## 1. 需求分析

### 1.1 背景与目标

通过课程设计综合运用 Java GUI、网络编程与数据库开发技术，实现一个具备基本社交与聊天交互能力的桌面应用。

### 1.2 功能需求

客户端（QQClient）：
- 登录（记住密码）
- 注册新用户（含密保问题/答案）
- 找回密码
- 主界面：好友列表、在线状态显示
- 搜索用户/添加好友、删除好友
- 聊天窗口 UI（表情、字体、气泡等资源）

服务端（QQServer）：
- 监听客户端连接、为每个连接创建会话线程
- 登录校验与重复登录控制
- 注册用户写入数据库
- 查询用户信息、查询好友列表
- 添加好友/删除好友
- 服务端窗口显示在线用户数量

数据库（MySQL）：
- 用户表 `UserInfo`
- 好友关系 `Friends`
- 登录状态 `Login`
- 密保信息 `GetPwdInfo`
- 聊天文本 `Text` 与聊天记录索引 `ChatInfo`（为聊天记录持久化预留）

### 1.3 非功能需求

- 可运行性：Windows + JDK + MySQL 环境可直接启动
- 易用性：Swing 图形界面
- 可维护性：客户端/服务端分模块组织

## 2. 总体设计

### 2.1 系统架构

系统采用典型 C/S 架构：

- 客户端：负责 UI 与交互、向服务端发送请求
- 服务端：负责业务处理、数据库访问、在线状态维护
- 数据库：负责持久化用户与关系数据

架构与时序图见：`docs/diagrams/architecture.md`。

### 2.2 模块划分

#### 2.2.1 客户端模块

- `com.client.view`：界面层（如 `JLoginFrm`、`JMainFrm`、`JChatFrm`）
- `com.controller`：与服务端通信控制（如 `ClientToServer`、`ClientToServerThread`）
- `com.client.model.*`：UI 组件/资源管理
- `com.common`：公共数据结构（User、UserInfoBean、Message 等）

客户端入口示例：`QQClient/src/com/client/view/JLoginFrm.java`。

#### 2.2.2 服务端模块

- `com.controller`：服务端会话处理核心（`Server` 实现 `Runnable`）
- `com.controller.ServerThread`：监听与连接接入
- `com.server.service`：JDBC 连接与数据访问工具
- `com.server.view`：服务端界面（在线用户列表/数量）
- `com.common`：与客户端共享的消息与实体类

服务端核心处理：`QQServer/src/com/controller/Server.java`。

## 3. 详细设计

### 3.1 通信协议设计

本项目采用“字符串指令 + 顺序字段写入”的方式实现轻量协议。

示例（登录）：

- 客户端发送：
  1) `"login"`
  2) `qq`
  3) `pwd`
  4) 客户端接收消息端口 `clientReceivePort`
  5) 客户端 IP `clientIP`
- 服务端返回：`loginSuccess`/`loginFail`/`reLogin`，成功后继续返回用户信息与好友列表。

优点：实现简单，便于课程设计演示。缺点：可扩展性弱、字段顺序强依赖。

### 3.2 数据库设计

数据库脚本：
- 原始：根目录 `myqq.sql`
- 整理版：`docs/sql/schema.sql`

核心表说明：

- `UserInfo(qq,pwd,nickname,...)`：用户基本信息
- `Friends(qq,fqq,fsno,...)`：好友关系（以发起者 qq 为主键的一侧）
- `SubGroup(sno,sname,qq)`：分组信息
- `Login(lip,lport,lstatus,lqq)`：在线状态（用于重复登录判断与在线显示）
- `GetPwdInfo(question,answer,qq)`：密保问题/答案
- `Text/ChatInfo`：聊天记录存储结构（可扩展为历史消息）

### 3.3 关键流程设计

#### 3.3.1 登录

见 `docs/diagrams/architecture.md` 登录时序图。

服务端登录处理位置：`QQServer/src/com/controller/Server.java` 的 `login()`。

#### 3.3.2 注册

服务端逻辑：
- 查询 `UserInfo` 最大 QQ 号并自增作为新账号
- 插入 `UserInfo`
- 插入三条 `GetPwdInfo` 作为密保
- 将新 QQ 号回写给客户端

相关代码：`QQServer/src/com/controller/Server.java` 的 `registerNewUser()`。

#### 3.3.3 好友列表/在线状态

- 服务端根据 `Friends` 表查找好友 qq
- 逐个查询 `UserInfo` 获取好友信息
- 查 `SubGroup` 获取分组名
- 查 `Login` 判断是否在线（存在则在线，并返回 IP/PORT）

相关代码：`QQServer/src/com/controller/Server.java` 的 `queryFriend()`。

## 4. 主要实现

### 4.1 客户端实现要点

- Swing 界面：无边框窗口、资源管理（背景图/按钮/表情）
- 与服务端通信：`ClientToServer` 通过 Socket 发送指令并读取返回，登录成功后创建主界面

示例入口：`JLoginFrm#main`。

### 4.2 服务端实现要点

- 每个客户端连接对应一个 `Server` 会话线程，循环读取指令并分发处理
- JDBC：通过 `ConnectionFactory` 获取连接，执行查询/更新
- 在线维护：登录成功插入 `Login` 表，退出时删除

## 6. 知识要点总结（课程要求对应）

### 6.1 Java 基础与面向对象

- **类与对象**：客户端/服务端按功能拆分为多个类（UI 类、控制类、数据类）。
- **封装**：`UserInfoBean`、`Message` 等用于封装业务数据，减少参数传递复杂度。
- **继承与接口**：
  - Swing 界面类继承 `JFrame/JWindow`；
  - 事件处理实现 `ActionListener/ItemListener`；
  - 服务端会话处理实现 `Runnable`。

### 6.2 Java GUI（Swing）

- **常用组件**：`JFrame/JPanel/JList/JTextArea/JButton` 等完成登录、主界面、服务端控制台。
- **事件驱动模型**：通过监听器响应用户操作（按钮点击、输入事件）。
- **资源与界面美化**：通过 `image/` 下的图片资源实现皮肤、按钮、表情等。

### 6.3 网络编程（Socket）

- **C/S 架构**：客户端主动连接，服务端 `ServerSocket` 监听端口并接入连接。
- **TCP 数据传输**：使用 `Socket` + `DataInputStream/DataOutputStream` 进行请求/响应。
- **应用层协议**：采用“字符串指令 + 字段顺序”实现业务请求（login/register/queryFriend 等）。

### 6.4 多线程与并发

- **并发处理模型**：服务端监听线程接入连接后，为每个连接创建会话线程，循环读取指令并处理。
- **线程管理**：通过线程管理类集中维护在线会话，便于广播通知与在线人数显示。

### 6.5 数据库与 JDBC

- **数据库建模**：使用 `UserInfo/Friends/Login/GetPwdInfo` 等表实现用户、好友、在线状态与密保功能。
- **JDBC 连接流程**：读取 `jdbcCon.properties` → 加载驱动 → `DriverManager.getConnection` 建立连接。
- **SQL CRUD**：通过 `PreparedStatement` 执行增删改查，`ResultSet` 读取查询结果。

### 6.6 配置与可运行交付

- **配置文件**：
  - `QQClient/src/ServerInfo.properties`：服务端 IP/端口
  - `QQServer/src/jdbcCon.properties`：数据库连接
- **可运行文档**：提供零基础运行指南、SQL 脚本与架构图，保证环境可复现。
