# 架构与流程图（Mermaid）

## 1. 总体架构

```mermaid
flowchart LR
  subgraph Client[QQClient（Swing）]
    UI[界面层：JLoginFrm/JMainFrm/JChatFrm]
    Ctl[控制层：com.controller.ClientToServer 等]
    Model[公共模型：com.common（Message/User/UserInfoBean 等）]
  end

  subgraph Server[QQServer（Socket + JDBC）]
    SFrame[服务端界面：ServerFrame]
    SListen[监听：ServerThread]
    SWorker[会话处理：com.controller.Server（Runnable）]
    DB[(MySQL: myqq)]
    DAO[DB工具：ConnectionFactory/Query/Dml]
  end

  UI --> Ctl -->|TCP Socket(DataInput/OutputStream)| SListen --> SWorker
  SWorker --> DAO --> DB
  Ctl <--> Model
  SWorker <--> Model
```

## 2. 登录流程

```mermaid
sequenceDiagram
  autonumber
  participant C as Client(JLoginFrm/ClientToServer)
  participant S as Server(Server)
  participant DB as MySQL(UserInfo/Login)

  C->>S: "login" + qq + pwd + clientReceivePort + clientIP
  S->>DB: 校验UserInfo(qq,pwd)
  S->>DB: 校验Login(lqq=qq, lstatus=1)
  alt 账号存在且未重复登录
    S-->>C: loginSuccess
    S->>DB: INSERT Login(lip,lport,ldate,lstatus,lqq)
    S-->>C: 返回当前用户UserInfo
    S-->>C: 返回好友列表 Friends + UserInfo + Login(在线状态)
  else 重复登录
    S-->>C: reLogin
  else 账号/密码错误
    S-->>C: loginFail
  end
```

## 3. 好友列表拉取

```mermaid
sequenceDiagram
  autonumber
  participant C as Client(ClientToServer)
  participant S as Server(Server)
  participant DB as MySQL(Friends/UserInfo/SubGroup/Login)

  C->>S: "queryFriend" + qq
  S->>DB: SELECT fqq,fsno FROM Friends WHERE qq=?
  loop 每个好友
    S->>DB: SELECT * FROM UserInfo WHERE qq=fqq
    S->>DB: SELECT sname FROM SubGroup WHERE sno=fsno
    S->>DB: SELECT lip,lport FROM Login WHERE lqq=fqq
    S-->>C: friendInfo + subgroupName + online/offline
  end
```
