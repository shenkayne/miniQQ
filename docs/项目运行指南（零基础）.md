# miniQQ 项目运行指南（零基础）

适用人群：**完全零基础**。

目标：让你在 Windows 上把 miniQQ **成功运行起来**（服务端能启动、客户端能打开并登录）。

本项目已附带安装包：
- MySQL 安装器：`docs/assets/mysql-installer-community-8.0.46.0.msi`

JDK 推荐使用 **JDK 8（Java 8）**（你提供的下载归档地址：`https://jdk.java.net/archive/`）。

> 本指南默认：MySQL root 密码为 **123456**。

---

## 一、你需要准备什么

1) Windows 10/11
2) IntelliJ IDEA（建议用社区版即可）
3) 本项目源码（miniQQ）

建议把项目放在**纯英文路径**，例如：
- `D:\miniQQ\miniQQ`

---

## 二、安装 JDK 8（Java 8）

你提供的 JDK 下载归档地址：`https://jdk.java.net/archive/`。

> 注意：该页面主要是 OpenJDK 的历史归档，未必长期提供“8u”版本；如果找不到 JDK 8，请改用 Oracle JDK 8 / Adoptium Temurin 8 等渠道。

### 2.1 安装/解压

- 安装版（.exe）：双击安装，记住安装路径
- 压缩包（.zip）：解压到例如 `C:\Java\jdk1.8`

完成后应存在：`C:\Java\jdk1.8\bin\java.exe`

### 2.2 配置环境变量（一次即可）

1) 打开环境变量：
- 右键“此电脑” → 属性 → 高级系统设置 → 环境变量

2) 新建系统变量：
- 变量名：`JAVA_HOME`
- 变量值：`C:\Java\jdk1.8`（按你的实际安装路径填写）

3) 编辑系统变量 `Path`，新增一条：
- `%JAVA_HOME%\bin`

4) 新开一个命令行窗口验证（必须新开）：

```bat
java -version
javac -version
```

看到版本号包含 `1.8` 即成功。

---

## 三、安装 MySQL 8.0（用已附带 msi 安装器）

安装包下载网址：https://dev.mysql.com/downloads/windows/installer/8.0.html
- `mysql-installer-community-8.0.46.0.msi`

按下面选（零基础照抄）：

1) **Setup Type**：选 `Server only`
2) **Config Type**：选 `Development Computer`
3) **端口**：保持 `3306`
4) **认证方式**：保持默认，一路 Next
5) **root 密码**：设置成 `123456`
6) **Windows Service**：
   - 勾选 `Configure MySQL Server as a Windows Service`
   - Service Name 默认（通常为 `MySQL80`）
   - 点击 `Start Server`

### 3.1 验证 MySQL 服务是否在运行

打开命令行执行：

```bat
sc query MySQL80
```

- 如果看到 `RUNNING`：说明 MySQL 正常。
- 如果报“找不到服务名”：说明你的服务名不是 MySQL80。
  - 打开 Windows “服务”（services.msc），找到 MySQL 的服务名，替换上面的 MySQL80 再查。

### 3.2 验证是否能登录 MySQL

```bat
mysql -uroot -p
```

输入密码：`123456`

看到 `mysql>` 就说明成功。

## 四、导入数据库（建库/建表/数据）

### 4.1 推荐导入方式（一次导完）

进入 MySQL 后（看到 `mysql>`），执行：

```sql
SOURCE D:/02-coding/03_Projects/00_Vscode/miniQQ/miniQQ/myqq.sql;
```

> 注意：路径按你自己的实际项目位置修改；Windows 下建议用 `/`。

### 4.2 验证导入成功

```sql
USE myqq;
SHOW TABLES;
SELECT qq,nickname FROM UserInfo LIMIT 5;
```

能看到表名和用户数据即成功。

## 五、配置项目（非常关键）

### 5.1 配置服务端数据库连接

打开文件：`QQServer/src/jdbcCon.properties`

把它改成（默认 root/123456，本机 3306）：

```properties
username=root
password=123456
url=jdbc:mysql://localhost:3306/myqq?characterEncoding=utf8&useSSL=false&serverTimezone=UTC&rewriteBatchedStatements=true
driver=com.mysql.cj.jdbc.Driver
```

### 5.2 配置客户端连接服务端的地址/端口

打开：`QQClient/src/ServerInfo.properties`

默认是：

```properties
serverip = 127.0.0.1
servertcp.port = 9999
```

如果客户端和服务端在同一台电脑运行，这样就行。

> 服务端端口在代码里默认就是 9999（见 `QQServer/src/com/controller/ServerThread.java` 的 `getPort()`）。

## 六、用 IntelliJ IDEA 把项目跑起来

### 6.1 导入项目

1) 打开 IntelliJ IDEA
2) 选择 `Open`
3) 选择项目根目录：`miniQQ/miniQQ`
4) 等待 IDEA 索引完成

### 6.2 重要：添加第三方依赖（否则无法编译/无法连库）

本项目不是 Maven/Gradle 工程，第三方依赖需要用 jar 方式引入。

项目根目录已创建：`libs/`，请把以下 **3 类依赖** 放进去（都是 JDK8 可用版本）：

- MigLayout（气泡/布局）：
  - **注意：`miglayout-core` 与 `miglayout-swing` 版本必须一致**（例如都为 5.2）。
  - `libs/miglayout-core-5.2.jar`
  - `libs/miglayout-swing-5.2.jar`
  > 说明：版本混用会触发 `NoSuchFieldError: VISUAL_PADDING_PROPERTY`。

- NinePatch（九宫格气泡图片）：
  - `libs/ninepatch-*.jar`
  > 说明：该 jar 必须是 **Java 8 编译**（class 版本 52.0）。如果报“类文件版本 55.0，应为 52.0”，说明你下到了 Java 11 的 jar，需要换低版本。

- MySQL JDBC（服务端连库）：
  - `libs/mysql-connector-j-8.x.x.jar`

然后在 IDEA 里一次性添加依赖：

1) IDEA：`File` → `Project Structure...` → `Modules`
2) 依次选中 `QQClient` 和 `QQServer` 模块 → `Dependencies`
3) 点击 `+` → `JARs or directories...` → 选择 `miniQQ/miniQQ/libs` 目录
4) 选择 `Jar Directory`，勾选 `Add to module dependencies`
5) `Apply` → `OK`

### 6.3 启动服务端（先启动）

运行入口：
- `QQServer/src/com/server/view/ServerFrame.java`（有 `main` 方法）

启动后：
- 点击界面按钮 **“启动服务器/开始监听”**（界面按钮文字可能显示为乱码，但按钮位置在下方）
- 看到右侧日志输出“服务器启动成功…等待客户端连接”类似信息即成功

> 注意：`ServerFrame` 里默认不会自动 start 监听线程，需要你点击按钮触发（代码在 `pauseButton_actionPerformed`）。

### 6.4 启动客户端（后启动）

运行入口：
- `QQClient/src/com/client/view/JLoginFrm.java` 的 `main`

### 6.5 登录测试

数据库里已有默认账号（`myqq.sql` 内置了多条用户）：
- 账号：`10003` 密码：`123`
- 账号：`10005` 密码：`123`

能登录进主界面并看到好友列表，就说明跑通。

## 七、常见报错与解决

### 7.1 服务端报错：`No suitable driver` / `ClassNotFoundException: com.mysql.cj.jdbc.Driver`

原因：没添加 MySQL JDBC 驱动。

解决：按 **6.2** 添加 `mysql-connector-j` jar。

### 7.2 客户端报错：连接不上/超时

- 确保服务端已启动并在监听 9999
- 确认 `QQClient/src/ServerInfo.properties` 的 `serverip` 是 `127.0.0.1`
- 防火墙放行 9999（或临时关闭防火墙验证）

### 7.3 MySQL 无法登录

- 确认 MySQL 服务运行：`sc query MySQL80`
- 确认密码是 `123456`
- 如果端口不是 3306：需要同步修改 `jdbcCon.properties` 的 URL

## 八、验收标准（跑通即交付）

1) MySQL 服务是 RUNNING
2) `myqq` 数据库存在，能查询到 `UserInfo` 表数据
3) 服务端 `ServerFrame` 能正常启动，不再报 JDBC 错
4) 客户端能打开登录页，输入账号密码可登录

## 九、二次开发建议

- 将通信协议从“字符串指令 + 依次写入字段”改为统一的 `Message` 对象序列化（或 JSON）
- 敏感信息（密码）建议使用 hash（BCrypt）存储
- SQL 语句建议全部使用 `PreparedStatement` 参数化，避免注入风险
- 增加离线消息/聊天记录拉取接口（目前数据库已存在 `ChatInfo/Text` 表，但客户端 UI 流程需要补齐）
